# MindMaze

MindMaze is a 2D pixel-art roguelike shooter combining fast-paced, top-down combat with procedurally generated levels and a narrative exploring mental health.

Each run introduces different level layouts and challenges. Players navigate hostile environments, experiment with weapons and power-ups, and progress through a story centered on resilience and personal struggles.

**[Download MindMaze for Windows on itch.io](https://inaijin.itch.io/mindmaze)**

## Features

- **Procedural Level Generation:** Dynamically generated levels create different layouts, enemy encounters, and challenges across runs.
- **Top-Down Combat:** Fast-paced shooting mechanics with different weapons and power-ups.
- **Roguelike Gameplay:** Permadeath and progression mechanics encourage experimentation across repeated runs.
- **Narrative:** A story exploring mental health through its characters, environments, and gameplay.
- **Pixel-Art Visuals:** 2D environments and characters presented in a consistent pixel-art style.

## Download and Play

MindMaze is available as a downloadable Windows game.

1. Visit the [MindMaze itch.io page](https://inaijin.itch.io/mindmaze).
2. Download `MindMaze.zip`.
3. Extract the archive.
4. Launch the included game executable.

No separate installation is required.

## Development

MindMaze was developed as a five-person university team project for the Information Technology Project Management course at the University of Tehran.

The project involved coordinating development tasks and integrating gameplay mechanics, visuals, and narrative elements into a playable Windows release.
